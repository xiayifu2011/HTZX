# 放图片的地方

## 当前图片

| 文件名 | 用途 | 什么时候显示 |
|---|---|---|
| `bg.jpg` | 主背景 | 平时上课期间 |
| `bg2.jpg` | 假期背景 | 假期副本期间 |
| `bg_end.jpg` | 结局背景 | 中考结束、结局画面 |

## 图片风格约定

本项目统一使用**简约扁平矢量插画风格**（flat vector illustration）：

- 纯色块拼贴，无渐变、无纹理、无细节阴影
- 主色调清华紫 #660874，辅以暖橙、米白、深紫
- **不出现可辨认的真实人物、不含校服与肖像**
- **不使用校徽**（学校目前无官方校徽）
- 中部留出大片纯净区域，便于叠加游戏文字

## 更换图片

1. 新图片放进本文件夹（文件名用英文小写，如 `bg_new.jpg`）
2. 改 `js/02-config.js` 里 `theme` 对应的路径：
   ```js
   bgImage: "assets/bg_new.jpg",
   ```
3. 刷新网页即可，不用改任何其他代码

## 注意事项

- 建议尺寸 1600×900（16:9），单张不超过 300 KB
- 背景图会自动压暗（不透明度 0.26），保证文字看得清
- 需要美术加工时，可用 AI 把实景照重绘成扁平插画风再使用
