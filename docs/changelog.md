# 更新日志

## v1.1 · 屏幕情绪与更难的三年

**界面：会随你的状态变化**

- 压力爆表时四周涌起红雾，心态过低时整屏褪色灰暗，健康见底时画面发虚，经济紧张时边缘发冷
- 每档特效分轻/重两级，弹窗永远压在特效之上；回主菜单和进结局会自动清掉
- 屏幕自适应：根字号随视口宽度变化，1024 到 2560 宽都能一屏装下，不用滚
- 七套主题色可在主菜单切换，每套配一句文案（群星、草原、晨曦、深海、素墨、花灯）
- 英语模式：界面、属性名、行动、弹窗全部可切英文

**属性：模糊化**

- 面板上只看得到四项：心态 / 经济 / 健康 / 压力
- 除经济外，其余只显示「极低 / 较低 / 中 / 较高 / 极高」五档，不再给精确数字
- 效率 / 悟性 / 社交 / 亲情 仍在后台实时计算，但面板上不再出现
- 学科分数板块删除，各科只在考试事件里出现

**新增两个行动**

- 🏃 运动锻炼：消耗一次行动，换身体的底子，之后有概率连锁出运动类事件（新建 10 条）
- ✏️ 做题：按当前年级与科目出题，选择题或填空题；答对本科目加成，答错小幅倒扣

**更难的三年**

- 学习收益 ×0.80、遗忘 ×1.30、考试 ×0.94、学习带来的压力 ×1.40，并新增「一周没学习 → 全科再 -3%」
- 实测：认真玩（每周两次学习）初三约 75 分，只学一次约 60 分

**遗憾离场**

- 不再「压力一到 100 就崩」，改为连续三周爆表才提前结束，中途有两次预警
- 压力周结算改为向学业基线回归（原来是无回归的随机漫步，三年下来迟早撞上 100）

**亲情**

- 开口要钱会掉亲情（亲情越低掉得越多），亲情低于 40 会被念叨、打折，最低时大概率要不到钱
- 亲情低于 30 有概率触发家庭矛盾，三选一，认错和冷战都是实打实的负面

**破茧的另一面：天赋退化**

- 连续几周不学习，「过目不忘」「数学脑」「卷王」等学习天赋会一个个消失（共 13 条）
- 不运动则「运动健将」「钢筋铁骨」退化

**其它**

- 削弱天赋「家财万贯」：每周 +150 降到 +45，开局 300 降到 150
- 「单亲家庭」天赋：事件里爸爸妈妈的称呼会统一成同一位家长，不会再一会爸一会妈；留守少年则换成爷爷奶奶
- 开局可选难度与学期范围（初中三年 / 初二到初三 / 只玩初三 / 只玩初一），会写进存档
- 修掉一批提示动效问题：多条提示条不再叠在同一处，飘字错开排列
- 文档实时更新：改完 docs/*.md 刷新即生效（起本地服务时），或用弹窗里的「导入」按钮选文件/粘贴
- 全部文件名改为英文，启动脚本改为纯 ASCII，任何解压软件都不会乱码
- 暂不使用校园插画配图，改用七套主题自带的 CSS 渐变（想恢复就打开 `GAME_CONFIG.usePhotos`）

## v1.1.1 · 修一批看得见的问题

**英语模式暂停开放**

- 只译好了一部分，事件、天赋、书目仍是中文，切换后会出现半中半英和刷新不及时
- 现在点切换按钮会弹出「敬请期待」说明，不再真的切过去
- 已经切到英文的玩家，再点一次可以切回中文，不会卡住
- 将来译完，把 `js/01b-i18n.js` 里的 `EN_READY` 改回 `true` 就会自动恢复

**属性栏：档位文字看得见了**

- 模糊化之后，「中 / 较高 / 较低」这些字被一个有颜色的方块盖住了 ——
  原因是文字颜色和背景色被写成了同一个值，等于红字画在红方块上
- 现在档位文字只有颜色、没有底色，刻度条的填充色单独画

**窗口不再被拉得老长**

- 根因：弹窗正文整体是 `white-space: pre-wrap`，而 HTML 是模板字符串拼的，
  源码里为了好看的换行和缩进，被 pre-wrap 一个个渲染成了真实空行
- 现在默认改回 normal，需要保留手动换行的地方（事件文案、破茧文案）单独声明
- 顺带收紧了正文行高（2 → 1.62）、块间距、以及 Markdown 的段间距
- 新手介绍从 4221px 缩到 2341px（-44%），天赋图鉴从 3885px 缩到 1908px（-51%）
- Markdown 新增「断句接回」：源文件里一句话被空行拆成两段，渲染时会自动接回一段

**主题对比度全面拉高**

- 描边（卡片边界）原来对比度只有 1.5~2.2，几乎看不见，界面显得糊 —— 现在提到 3.2+
- 次要文字从 7.7~9.1 提到 10.5，正文提到 15+
- 青草主题按要求往白色靠：正文改用近白，强调色与背景渐变一起提亮

## v1.1.2 · 修代码泄漏、读书出身、存档与题库

**修掉界面上泄漏出来的代码**

- 主题卡片上会显示一整串 `style="--c1:#8a2b9c;..."` ——
  原因是弹窗正文把换行统一转成了 `<br>`，连 HTML 标签内部为了缩进产生的换行也一起转了，
  标签结构被破坏，属性内容就变成了可见文字
- 现在换成精确的 `nl2br()`：只转「夹在真实文字之间」的换行，
  标签内部的原样保留，元素之间的直接丢掉。既不丢文案换行，也不会多出空行

**读书不再改变出身**

- 出身类天赋（家财万贯 / 家徒四壁 / 书香门第 / 单亲家庭 / 留守少年 …）
  现在只能由开局抽到，读书、社团、事件一律不发
- 读再多书也没法把「家徒四壁」读成「书香门第」
- 清单在 `js/03-data-talents.js` 的 `FAMILY_TALENTS`，想调整改一处即可

**存档机制**

- 每周所有结算走完之后自动存一次，读档正好回到新周的开端，不丢任何已结算内容
- 中考分数算出来、以及进入结局时也会立刻落盘
- 存档加了结构版本号；读档时会做可用性检查，坏数据自动清空而不是让主菜单打不开
- 写不进去（隐私模式 / 空间满）会提示，不再静默失败
- 主菜单会显示「自动存档 第 N 周」，玩家知道进度被记住了

**题库 42 → 136 题**

- 九科齐全，初一可抽 41 题、初二 90 题、初三 112 题
- 体检脚本新增「死题检测」：题目年级高于该科能出现的最高年级时会被提醒
  （生物 / 地理只考到初二，标了初三的题永远抽不到，已修正 5 条）

**判卷更宽容**

- 一 / 1 / 1.0 / 01 都算对
- 1/2 / 0.5 / 二分之一 / 50% 都算对
- 大小写不分、空格随便加、书名号括号可省、单位可写可不写（4cm ↔ 4）
- `x=4` 和 `4` 互认
- 实测 8 道题用各种等价写法作答，全部判对

## v1.0 · 正式版（发布版）

这是第一个完整版本。界面、数值、文案、体检脚本全部过了一遍，
可以作为社团成果提交审核、在全校展示。

**界面：更紧凑，少滚滚轮**

- 弹窗内边距、行间距整体收紧（正文行高 1.8 → 1.55），字少不再空一大片
- 行动面板改为**单列竖排**，六个选项一眼看全
- 主界面左栏合并：天赋 + 道具并成一张卡，各科 + 成绩并成一张卡
- 按钮、卡片、日志区、成就格、Markdown 文档的间距统一压缩

**修掉一批会影响体验的问题**

- 读档后社团会消失 —— 社团、手机标记、事件冷却原本根本没存进存档，已补齐
- 「向父母要零花钱」时，父母的台词弹窗会被后面的随机事件直接盖掉，已改成说完再继续
- 剧情模式（story）下仍可能因经济归零而「辍学打工」提前结束 ——
  与该难度「不会中途暴毙」的承诺不符，已加经济保底线
- 学力衰减在一周内被计算了两次（每次行动一次 + 周结算一次），
  导致初三时衰减量超过学习量、学力一路跌回个位数，已去掉重复计算
- 体检脚本新增：社团奖励天赋校验、时段/季节合法性校验、
  「写了却永远拿不到」的死成就检测、条件分支里的指令错别字检查

**结局与成就**

- 「少年班」「平凡而幸福」两条结局排在了分数结局后面，条件再符合也轮不到，已重排
- 「冠军之心」「锦鲤本鲤」「竞赛之星」「青春悸动」「干饭之魂」五个成就
  没有任何地方会为它们计数，已接上计数并补充事件
- 「六边形战士」把「压力」也算成一条边（压力高是坏事），已改为只算六项主属性
- 补上社团表里缺失的奖励天赋【匠心】【逻辑鬼才】（天赋数 80 → 82）

**内容与文案**

- 每条随机事件都标注了时段（周中 / 周三社团课 / 周末），
  不会再出现「住校却半夜接手机」「周末还在教室随堂小测」这类时间错误
- 新增事件：校门口的小吃摊、课桌里的纸条、陪妈妈去赶集、周日的作业、
  周末的一顿饭、爬一次红塔山、体艺节前的排练、黑板右上角（初三）、百日誓师
- 「社团招新周」与固定日程的社团展演重复，改为「社团开放日」（未入社时才出现）
- 「体育艺术文化节」与固定日程撞车，改为节前的排练
- 天赋诗句去重 16 处（多处引用同一句诗），并为新增天赋补了诗句
- 大量事件、书目、道具文案改写，增强文学性与玉溪本地气息

**数值**

- 中考公式里学力的权重过低（0.7），学力几乎不影响分数，
  天天摸鱼和天天学习考出的分差不多。已提到 1.3，并把权重做成
  `js/02-config.js` 里可调的 `exam.subjWeight`
- 参考值（剧情模式）：均衡游玩 ≈ 87 分，偏重学习 ≈ 88 分，长期摸鱼 ≈ 73 分

## v0.9 · 时间与社团版本

**新增**

- 校历时间系统：月份、季节（春夏秋冬），顶栏实时显示
- 一周分「周中 / 周末」两个时段，按时间先后顺序推进
- 时段数量**动态调整**：上周攒下的后续事件会让对应时段自动延长
- 社团系统：红塔中学 16 个社团
  - 初一上第 1~3 周周末**抢社团**，热门社团手慢无
  - 入社后社团事件均匀分布在学期中
  - 长期参与（6 次）可能获得天赋
  - 每个社团有每周微小加成
- 事件分布开关 `dist`：
  - `uniform` 均匀分布（距上次越久概率越高）
  - `decay` 出现后衰减
  - `front` 前期多 / `back` 后期多
- 事件时段字段 `slot`、季节字段 `season`、月份字段 `months`
- 事件最小间隔 `minGap`，避免扎堆
- 选项**条件分支** `branch`：同一选项按数值走向不同结果
- 后续事件挂起 `raise`：不立刻触发，而是在几周内提高概率
- 标记系统 `flag`：例如"有没有把手机带到学校"
- 手机事件链：返校前选择 → 带手机才可能被查到 → 被抓有后果
- 四季观景事件：春（操场边先绿了）、夏（吊扇与蝉鸣）、冬（早读时天还没亮）
- 主菜单三个按钮：新手介绍 / 更新日志 / 鸣谢列表（内容在 docs/*.md 里改）

**调整**

- 宿舍熄灯事件去掉手机选项，改为「和室友聊到很晚」（手机玩法独立成链）
- 秋日林荫道改为只在秋季出现
- 事件选择引擎重写，支持时段、季节、分布、间隔、挂起
