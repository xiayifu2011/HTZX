# 项目结构大纲

给 AI 或新同学看这一份，就能知道该改哪个文件。

## 一句话概括

**改玩法内容 → 动 `js/0x~12`；改游戏规则 → 动 `js/13~19`；改学校特色 → 只动 `js/02-config.js`。**

---

## 目录总览

```
zhongkao-life/
├─ index.html          ← 页面骨架（只有 div 的位置，没有逻辑）
├─ css/                ← 外观（颜色、动画、布局）
├─ js/                 ← 全部逻辑，按数字顺序加载
├─ docs/               ← 说明文档（本文件在此）
├─ tools/              ← 辅助脚本（体检、打包）
└─ assets/             ← 图片（校徽、背景、事件配图）
```

**文件名前面的数字就是加载顺序**，不要调换。

---

## css/ 四层

| 文件 | 管什么 | 什么时候改 |
|---|---|---|
| `01-base.css` | 配色变量、背景、标题、整屏布局 | 想换主色调、改背景 |
| `02-components.css` | 按钮、卡片、属性条、徽章、日志区、行动面板 | 改按钮样式、字号 |
| `03-modal.css` | 弹窗、天赋详情卡、飘字、提示条、成就格 | 改弹窗外观 |
| `04-theme.css` | 流光特效、学校皮肤、弹窗徽章、事件进度条 | 加校徽、换背景图时自动生效 |

> 想改颜色，优先改 `01-base.css` 顶部的 `:root` 变量（如 `--gold`、`--purple`），一处改全局生效。

## js/ 十九个文件

| `03-data-talents.js` | 80 个天赋：等级、矛盾项、效果、诗句 | ★★ |
| `04-data-subjects.js` | 各年级考哪些科目 | ★ |
| `05b-data-clubs.js` | **16 个社团** + 32 条社团事件 + 抢社团逻辑。注意它必须在事件表之后加载 | ★★ |
| `05-data-shop.js` | 小卖铺 10 件道具 | ★★ |
| `06-data-books.js` | 班级图书角 26 本书 + `BAD_TALENTS` 负面天赋名单 | ★★ |
| `07-data-events.js` | 22 条通用随机事件 | ★★★ 最常改 |
| `08-data-events-school.js` | **红塔中学专属事件 15 条**（单独放，升级不冲突） | ★★★ 必改 |
| `09-data-fixed.js` | 开学/月考/期中/期末/运动会/假期副本/考场悟道 | ★★ |
| `10-data-achievements.js` | 34 个成就的达成条件 | ★★ |
| `11-data-endings.js` | 14 种结局 | ★ |
| `12-data-cures.js` | 19 条"破茧"（负面天赋消除）及鼓励文案 | ★★ |

### 🔵 引擎层（一般不动，改前先问）

| 文件 | 职责 |
|---|---|
| `01-utils.js` | 随机数、数值夹取、属性增减 `modProp()`、日志 `say()`、飘字。**所有 NaN 防护在这里**。属性区间 `PROP_RANGE`、主界面显示哪些属性 `PROP_HUD` 也在这里 |
| `13-engine-effects.js` | 中文指令解释器 —— 让不会编程的人也能写事件后果 |
| `14-engine-talent.js` | 天赋的获得、矛盾裁剪、等级上限、悟性消耗 |
| `15-engine-study.js` | **数值平衡**：难度曲线、学习收益、遗忘、考试分数、中考、`allowanceSettle()` 向父母要零花钱 |
| `16-flow.js` | 主循环：开周 → 选行动 → 弹事件 → 结算 → 下一周 |
| `17-ui.js` | 界面渲染 + 统一弹窗系统 |
| `18-save.js` | 三个存档槽的读写 |
| `19-boot.js` | 启动点火 |

## 数据是怎么流动的

```
玩家点按钮
   ↓
16-flow.js  takeAction()          ← 选了"努力学习"
   ↓
15-engine-study.js  studySettle() ← 算出各科涨了多少
   ↓
16-flow.js  runEventChain()       ← 排出事件弹窗（一次一个）
   ↓
16-flow.js  buildEventDef()       ← 从 07/08 事件表里挑一条
   ↓
13-engine-effects.js  runEffectSpec() ← 执行这条事件写好的后果
   ↓
01-utils.js  modProp() / say()    ← 改数值、写日志
   ↓
16-flow.js  afterWeek()           ← 周结算（属性漂移、全科遗忘）
   ↓
17-ui.js  renderHUD()             ← 刷新界面
   ↓
下一周
```

**想改"学生学得动/学不动"** → 只看 `15-engine-study.js` 的 `studySettle()`。
**想改"事件多不多"** → 只看 `02-config.js` 的 `actionsPerWeek` 和 `chainChance`。

## 弹窗的四种类别

玩家在弹窗右上角能看到徽章，这是理解游戏节奏的关键：

| 徽章 | 类别 | 是否占用"本周行动" |
|---|---|---|
| ⚡ 事件 1/4 | 随机事件 | **占用**，顶部有圆点进度 |
| 📅 固定事件 | 开学/考试/运动会/假期副本 | 不占 |
| 🎒 自由操作 | 小卖铺/道具/天赋图鉴/成就 | 不占 |
| 📚 本周行动 · 读书角 | 读书角算一次行动 | 占行动，但不占事件额度 |
| 🌱 破茧 | 负面天赋被消除 | 不占 |
| 🏁 结局 | 初中落幕 | — |

## 让 AI 改代码时怎么说

❌ 不好的说法："帮我改一下游戏"

✅ 好的说法（AI 只需读一个小文件，省钱又准）：

- "改 `js/08-data-events-school.js`，在末尾再加 3 条关于社团招新的事件"
- "改 `js/02-config.js`，把每周行动次数改成 1"
- "改 `js/15-engine-study.js` 的 `studySettle()`，让学习收益提高 20%"
- "改 `js/12-data-cures.js`，把"厌学"的消除次数从 12 改成 8"

## 隐藏属性：亲情

「亲情」在 `PROP_RANGE` 里，但**不在 `PROP_HUD` 里**，所以不占主属性栏，
只在属性栏末尾显示一行小字。改显示与否看 `js/01-utils.js` 的 `PROP_HUD`。

---

## 新增文件的加载顺序

`00-docs` → `01` → `02` → `02b` → `03~08` → **`05b`（必须在 07/08 之后，因为它要把社团事件并入 EVENTS）** → `09~19`

改 `index.html` 里的 script 顺序时要留意这一点。

## 学校定制落在哪

| 想改的学校元素 | 改哪个文件 |
|---|---|
| 校名、校训、四立、立行号 | `js/02-config.js` → `school` |
| 主题色、背景图 | `js/02-config.js` → `theme` |
| 学校专属事件 | `js/08-data-events-school.js` |
| 开学文案、运动会主题 | `js/09-data-fixed.js` |
| 结局文案（立行号到站） | `js/16-flow.js` → `gameOver()` |

背景切换用 `setBackground("main" | "alt" | "end")`，
在开局、假期副本、结局、返回主菜单处自动调用。

## 和单文件版的关系

`中考人生模拟器_优化版.html` 是拆分前的单文件版本，保留作对照。
**今后一律维护 `zhongkao-life/` 这个目录**，单文件不再更新。
需要单文件时，用 `tools/make-single.js` 从目录重新打包即可。
