## 素材来源

- 校训「人生在立，行达天下」、立行文化四立 —— 学校公开宣传材料
- 「立行号」列车意象、「每一步都算数」 —— 学校迎新物料
- 体育艺术文化节主题「行者」 —— 学校第二届体艺节
- 玉溪花灯戏、聂耳与国歌 —— 玉溪本土非遗与红色文化
- 社团名录、寄宿制生活细节 —— 学校公开报道

## 关于图片

- 背景图为校园实景的**扁平矢量插画风格艺术化重绘**
- 不含真实人物肖像、不含校服与学生照片
- **学校目前没有官方校徽，游戏不使用校徽图标**，只用校名与校训文字

## 技术
- 纯原生 JavaScript / HTML / CSS，无任何第三方库
- 无联网请求，数据保存在本机浏览器
- 无广告、无付费、无个人信息采集
