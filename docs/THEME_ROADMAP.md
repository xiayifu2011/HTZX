# 主题系统优化方向（v1.2 路线图）

这份文档整理自一轮配色设计讨论（清华紫 / 群星 / 晨雾草野 / 墨韵 / 灯感），
对照我们现有代码的差距，按优先级排出可落地的改造点。

只写方向与做法，不改代码。要做哪一项时照着「落点」改即可。

---

## 现状速览

| 项 | 现在 | 说明 |
|---|---|---|
| 主题数 | 7 套 | hongta / stars / grassland / dawn / abyss / ink / lantern |
| 每套构成 | 约 22 个 CSS 变量 + 1 条 `bgGrad` | 定义在 `js/02c-themes.js` |
| 对比度 | 正文 15~16.6、次要 10.5、描边 3.2+ | v1.1.1 已统一拉高 |
| 背景 | `body::before` 两层（图片 + 渐变）+ `::after` 一层压暗 | `css/04-theme.css` |
| 动效 | 只有标题金色流光（`goldPulse` / `rainbowFlow`） | 主题本身完全静止 |
| 变量命名 | 扁平：`--brand` `--purple` `--gold` `--txt` `--dim` | 无语义分层 |

## P0 · 收益最大，改动可控

### 1. 主题呼吸光晕

**差距**：每套主题都是静止的。配色方案里反复出现的「呼吸感」，靠的是
`box-shadow` 或 `radial-gradient` 的极慢明暗起伏，我们完全没有。

**做法**：在 `body::after` 之上加一层 `.theme-breath`（`position:fixed; inset:0; z-index:-1; pointer-events:none`），
背景用 `radial-gradient(1200px 800px at 50% 30%, rgba(var(--glow), .05), transparent 70%)`，
挂 `animation: themeBreath 12s ease-in-out infinite`，只动 `opacity`（0.4 ↔ 1），
幅度控制在 0.03~0.06 之间 —— 只是"呼吸"，不能是"闪烁"。

**落点**：`css/04-theme.css` 加一层 + 一个 `@keyframes themeBreath`

**必须同时做**：
- 每套主题可以自己定呼吸周期（`--breath-dur`，默认 12s）：草原慢一些 14s，花灯快一些 9s
- `@media(prefers-reduced-motion:reduce)` 里关掉（`css/05-mood.css` 已有先例，照抄）
- 游戏内红雾（`css/05-mood.css`）盖在呼吸层之上，不要互相打架（注意 z-index）

### 2. 背景拆成多层渐变

**差距**：现在 `bgGrad` 是一条完整的 `radial-gradient` 字符串，每套主题写死。
星云、晨雾这类效果需要 2~3 层不同大小、不同位置的光斑叠加，一条不够用。

**做法**：把 `bgGrad` 拆成 `--bg-grad-1 / --bg-grad-2 / --bg-grad-3`，
`body::before` 的 `background-image` 依次叠加，某层留空就自动跳过。

**落点**：`js/02c-themes.js`（变量）+ `css/04-theme.css`（叠加写法）

**示例方向**：
- 群星：一层深空底 + 一层偏蓝的星云 + 一层偏紫的远星
- 草原：一层草地绿 + 一层晨雾白（低饱和、高明度、大范围）
- 花灯：一层暗红 + 一层暖橙光晕（小范围、靠上）

### 3. 对比度自检进体检脚本

**差距**：v1.1.1 那次对比度是临时脚本算的，之后加新主题没人校验。

**做法**：`tools/check-content.js` 增加「主题自检」段，遍历 `THEME_SKINS`，
逐套算 WCAG 对比度，不达标就中文报错：
- 正文 `--txt` / `--panel` ≥ 12
- 次要 `--dim` / `--panel` ≥ 7
- 描边 `--line` / `--panel` ≥ 2.5
- 增益色 `--green` / `--panel` ≥ 4.5，减益色 `--red` 同

**落点**：`tools/check-content.js`

## P1 · 结构升级

### 4. 变量语义分层

**差距**：`--purple` 这个变量名在草原主题里存的是浅绿色，在深海主题里存的是青色 ——
名字和内容对不上，同学改主题时容易懵。

**做法**：新增一层语义变量，旧名保留为别名过渡：

| 新名 | 含义 | 现在对应 |
|---|---|---|
| `--surface` | 卡片底色 | `--panel` |
| `--surface-2` | 卡片内的浅底 | `--panel2` |
| `--border` | 描边 | `--line` |
| `--text` | 正文 | `--txt` |
| `--text-dim` | 次要文字 | `--dim` |
| `--accent` | 强调（不一定是紫） | `--purple` |
| `--accent-strong` | 强调深色 | `--purple2` |
| `--brand-1/2/3` | 按钮底色三档 | `--brand` `--brand-deep` `--brand-lite` |
| `--ok` `--warn` `--bad` | 语义色 | `--green` `--gold` `--red` |

**落点**：`js/02c-themes.js` 每套主题的 `vars` 里同时写新旧两套，
`css/01-base.css` 的 `:root` 里做别名映射。改完主题不动结构，逐步迁移。

### 5. 清华紫的层次问题

**差距**：学校官方色 `#660874` 是 色相 292°（偏品紫）、饱和 87%、明度 24%。
对照方案给的 `#5B2C8C` 是 色相 269°（偏蓝紫）、饱和 52%、明度 36% ——
我们的主色**更暗、更艳、更偏品红**。

**结论**：主色不能动（学校官方色，也是品牌识别）。但可以用配色方案的思路补层次 ——
「低饱和的浅色铺大面积，高饱和的深色只做点缀」：

- `--brand-lite` 现在是 `#8a2b9c`（饱和 73%），大面积铺会刺眼 → 往低饱和拉，参考 `#9b6fb5`
- 新增一档更浅的 `--brand-mist`（约 `#c9aede`），给 Hero 区、分隔线、选中态用
- 高饱和的 `#660874` 只留给按钮底色、图标、强调文字

**落点**：`js/02c-themes.js` → hongta 的 `vars`

### 6. 墨韵与灯感的东方气质

**差距**：`ink`（素墨）现在是纯灰阶，`lantern`（花灯）是暗红 ——
都还没做出「墨韵」的留白感和「灯感」的暖光。

**方向**：
- 墨韵：底色调成微暖的宣纸灰（不是纯中性灰），加一层极淡的双色渐变模拟纸纹；
  留白处（卡片间距）适当放大；描边压到更淡，让边界"化开"
- 灯感：主光晕改成暖橙 `radial-gradient`，范围小、靠上；
  文字用暖白而不是冷白；点亮态（选中、hover）加一圈暖色外发光

**落点**：`js/02c-themes.js` → ink / lantern 的 `vars` 与 `bgGrad`

## P2 · 锦上添花

### 7. 主菜单 Hero 区

现在主菜单是卡片列表，主题渐变没有铺开的地方。
可以在顶部加一块 Hero：校训「人生在立，行达天下」+「立行号」+ 当前主题的 tagline，
背景用主题渐变铺满。主题切换的观感会强很多。

**落点**：`index.html` 主菜单 + `css/04-theme.css`

### 8. 主题卡片升级成迷你色板

现在每张卡片只有一个圆点。可以改成 3~5 条色带（底色 / 卡片 / 强调 / 点缀），
一眼看出这套主题的气质，也方便同学改色时对照。

**落点**：`js/02c-themes.js` → `themeChipHtml()` + `css/04-theme.css`

### 9. 情绪变体（variant）

每套主题 2~3 种气质（如群星的「晴夜 / 极光 / 深空」），主菜单二级选择。
这个优先级最低 —— 先把 7 套做扎实，再考虑变体，否则维护成本翻倍。

## 做之前先确认的三件事

1. **主色不动**：`#660874` 是学校官方色，任何调整只在色阶上做文章，不改主色本身
2. **动效要能关**：所有新增动画必须有 `prefers-reduced-motion` 分支
3. **改完跑体检**：`node tools/check-content.js`，主题自检上线后会自动校验对比度
